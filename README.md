# Portafolio

## Portada

**Nombre del proyecto:** Portafolio
**Materia:** Programación Web
**Actividad:** Actividad 4
**Autor:** Francisco Javier González Santiago

### Descripcion de la actividad

La actividad se trata de crear un portafolio CV usando plantillas Bootstrap o TailwindCSS con datos reales de nuestras 
habilidades y actividades antes hechas, para hacer uso del framwork de html.

ESe deben de usar imagenes y datos reales aunque se puede añadir algunos datos ficticios ya que se quiere
mostrar el uso de estos frameworks

---

## Descripción del Framework

La plantilla se llama CLYDE, usa Bootstrap 4 con unas cuantas librerias para lograr un efecto mas interactivo en la
pagina

Se compone de las siguientes secciones:
- **HOME:** Inicio de la pagina, aparecen imagenes de presentacion en tipo carrusel
- **ABOUT:** Acerca de mi, es una introduccion de datos personales acerca del usuario
- **SKILLS:** Habilidades, numerando las habilidades que se dominan y que tanto se dominan
- **SERVICES:** Servicios, son los servicios que ofrece el ususario
- **PROJECTS:** Proyectos, Proyectos anteriormente realizados como experiencia
- **BLOG:** Blogs, Son paginas web tipo blog creados por el usuario
- **CONTACT:** Contacto, son datos personales para contactar directamente al usuario

Link de donde se puede descargar la plantilla:
<https://themewagon.com/themesfree-bootstrap-4-html5-responsive-portfolio-website-template-clyde/>

### Proceso de creación

1. Al inicio explore la plantilla poco a poco para ver que se le podria cambiar y que podria agregar en cada aspecto.
Me decidi en quitar la parte de blog, ya que no tendria ningun blog para poner ahi, y la seccion de testimonios
de clientes satisfechos, ya que viene con comentarios de dichos clientes
2. Lo primero fue elegir las fotos, tuve que editar la primera para que cumpliera con el formato necesario
y utilice la funcion del carrusel para enseñe la misma foto en todas las iteraciones del carrusel
3. Fui cambiando lentamente, seccion por seccion mis datos personales y **SOLAMENTE** cambiando 
letras sin agregar aun las imagenes, cambiando subtitulos, titulos descipciones, etc.
4. Al llegar a la parte de habilidades, en cada una de las barras de progreso de las habilidades se 
muestra que se ha trabajado en el ultimo mes, y eso se lo elimine para dejar la barra principal unicamente
5. Al llegar a la seccion de contacto, cree un numero falso y añadi la direccion del ITO para el 
contacto directo
6. Al terminar de escribir lo que fuera necesario, llego la hora de implementar las fotos, como en la 
seccion de proyectos, que tuve que sacar capturas de todos, o la seccion Acerca de mi, en la que tuve
que tomar la foto en el momento, modificarla un poco para que no apareciera tan cerca y volver a
borrarla y ponerla de nuevo una y otra vez
7. Por ultimo revise y me hacia falta quitar del indice de hasta arriba las secciones que habia borrado, y
ajustar los nombres de los archivos a (`portafolio.js`) y (`portafolio.css`) respectivamente
